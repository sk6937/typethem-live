04 FAQ

What is ♋?

♋ is “Cancer”, Unicode character U+264B. It belongs to the emoji set, so most modern phones and computers draw it as a small colour picture rather than plain text.

How do I type ♋?

Every method — Windows, Mac, HTML and CSS — is listed in the table above. The fastest route on a phone is the built-in emoji keyboard; on a computer, just tap the key above to copy ♋ to your clipboard.

What is the HTML or CSS code for ♋?

In HTML use &#9803; (decimal) or &#x264B; (hexadecimal). In a CSS content property use \264b.

Why does ♋ look different on other devices?

The character itself (U+264B) is identical everywhere — only the picture changes. Apple, Google, Microsoft and Samsung each design their own artwork for every emoji, which is why ♋ looks a little different on iPhone, Android and Windows.
