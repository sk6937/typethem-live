03 FAQ

How do I type these emoji on a computer?

On Windows press Win + . (period) to open the emoji picker; on a Mac press Control + Command + Space. You can also tap any key on this page to copy an emoji straight to your clipboard.

How do I add emoji on my phone?

On iPhone or Android, open any keyboard and tap the emoji key (the smiley or globe icon), then browse or search for the one you want. Copying from this page works too.

Why do these emoji look different on other devices?

Every emoji is a single Unicode character, but Apple, Google, Microsoft and Samsung each draw their own artwork for it — so the same emoji looks a little different across iPhone, Android and Windows while meaning exactly the same thing.

Can I use these emoji in usernames, bios and messages?

Most modern apps, chat tools and social networks accept emoji anywhere you can type. A few older systems or form fields strip them out — if one disappears, that field only accepts plain text.
